Data structures

A data structure is a way of organising data in memory. Which one you reach for depends on how the elements need to relate to each other — sitting in a line, or branching into a network.

1. Linear data structures

Elements sit in a single sequence. Each one has at most one predecessor and one successor, so you can walk the whole structure from start to end without ever choosing a branch.

StructureWhat it is
ArrayA fixed-size block of same-type values, reached directly by index.
StringA sequence of characters — an array with text-specific tooling on top.
Linked listNodes scattered across memory, each holding a pointer to the next.
StackLast in, first out — you add and remove at one end only.
QueueFirst in, first out — add at the back, remove from the front.

2. Non-linear data structures

One element can connect to many others through its links. The data branches or forms a network, so traversing it means deciding which path to follow at each step.

StructureWhat it is
TreeA hierarchy — one root at the top, every node pointing to its children.
Binary search treeAn ordered tree: smaller values left, larger ones right.
HeapA tree where every parent beats its children — smallest or largest on top.
GraphVertices joined by edges, any node free to reach any other.
Hash tableKeys mapped to slots by a hash function, giving near-instant lookup.

3. Choosing between them

Quick guide

Go linear when order matters and you process items in sequence. Go non-linear when the data is hierarchical, when relationships between items are arbitrary rather than sequential, or when you just need to find a value by its key as fast as possible.
