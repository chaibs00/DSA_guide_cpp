Data structures/Linear data structures

Arrays

An array stores multiple elements of the same type at contiguous memory locations. It's the simplest data structure there is, and the one nearly everything else is built on or measured against.

Two words that explain everything

  • Linear — the elements are stored one after another in a single sequence.
  • Contiguous — they sit next to each other in memory, with no gaps between them.

Each address increases by 4 bytes because an int usually occupies 4. Knowing the start address and the element size is enough to jump straight to any index — that's why arr[i] is O(1).

Static vs. dynamic

The split comes down to when the size is decided and where the memory lives.

Static arrayDynamic array
SizeFixed at declarationGrows and shrinks at runtime
MemoryStack, typicallyHeap
In C++int arr[5];std::vector<int>
Cost of resizingNot possibleAmortised O(1), occasional O(n)
Best forSmall, fixed, performance-critical setsAlmost everything else
Heap

The region of memory used for dynamic allocation. Variables there persist until you free them manually — or, with std::vector, until the vector goes out of scope and cleans up for you.
