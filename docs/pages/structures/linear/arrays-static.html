Linear data structures/Arrays

Static arrays

A static array has a fixed size, decided at declaration and unchangeable at runtime. That rigidity is the price for being fast, cheap and predictable.

Declaration

The size goes in square brackets after the name, and it must be known when the array is declared.

syntax
data_type array_name[size];
declare.cpp
// array to store integer values
int arr[5];

// array to store char values
char arr[10];

// an array of strings
string arr[12];

Initialising

There are several ways to fill an array at the moment you declare it.

initialise.cpp
// initialise while declaring
char arr[5] = { 'a', 'b', 'c', 'd', 'e' };

// let the compiler work out the size
int arr[] = { 1, 2, 3, 4, 5 };

// partial initialisation — the rest are value-initialised
string arr[10] = { "hello", "world", "!" };

// empty initialisation — every element is 0
int arr[5] = {};

Accessing elements

Each element is reached by its index. The first element is at index 0, the last at size - 1.

access.cpp
int arr[] = {10, 2, 7, 1, 3, 5, 1};

cout << arr[0];   // 10
cout << arr[1];   // 2
cout << arr[5];   // 5
cout << arr[10];  // out of bounds — garbage value

Each address is 4 bytes after the previous one, because an int usually occupies 4 bytes.

Watch out

C++ does not check bounds on a static array. Reading or writing past the end is undefined behaviour, not a clean crash — it may quietly return a garbage value or corrupt memory that belongs to something else.

Changing elements

Assignment through the index overwrites in place.

change.cpp
int arr[] = {5, 10, 15};

arr[1] = 100;

// arr is now {5, 100, 15}

Traversal

Visiting every element costs O(n) — one step per element, no shortcut.

Index-based loop

A static array doesn't carry its own length, so compute it from the total byte size divided by the size of one element.

traverse_index.cpp
int arr[] = {3, 5, 7, 9, 11};

// size of a static array
int size = sizeof(arr) / sizeof(arr[0]);

for (int i = 0; i < size; i++) {
    cout << arr[i] << " ";
}
// 3 5 7 9 11

Range-based loop

Shorter, and no size calculation needed.

traverse_range.cpp
int arr[] = {3, 5, 7, 9, 11};

for (int num : arr) {
    cout << num << " ";
}
// 3 5 7 9 11
Tip

The sizeof trick only works where the array is declared. Pass the array to a function and it decays to a pointer, so sizeof(arr) becomes the size of a pointer — pass the length alongside it, or use std::vector.
