C++ starter

C++ basics

The essential syntax before you touch a single data structure: reading input, core types, control flow, functions, and templates.

Write your first Hello World
hello.cpp
#include <iostream>

int main(){
    std::cout << "Hello world!";
    return 0;
}
  • #include <iostream> — includes the standard input/output library
  • int main() — the starting point of every C++ program
  • std::cout — sends output to the console
  • << — the output operator, streams data to the output
  • return 0; — indicates successful program execution

1. Getting user input

Let's read simple input from the user in C++, variables and their types must be declared before use.

Click to expand

Example using std::cin

input.cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    int age;

    std::cout << "Enter your name: ";
    std::cin >> name;

    std::cout << "Enter your age: ";
    std::cin >> age;

    std::cout << "Hello " << name << ", you are " << age << " years old.";
    return 0;
}
output
Enter your name: Alice
Enter your age: 60
Hello Alice, you are 60 years old.
Watch out

std::cin stops reading at the first whitespace. A name like "Alice John" only captures "Alice" — the next std::cin >> age then reads the leftover "John" instead of a number, silently producing 0.

output
Enter your name: Alice John
Enter your age:
Hello Alice, you are 0 years old.
Fix

Use std::getline(std::cin, name); instead of std::cin >> name; — it reads the whole line, spaces included.

output
Enter your name: Alice John
Enter your age: 10
Hello Alice John, you are 10 years old.

4. Conditional statements

Conditional statements let your program make decisions based on a condition.

Click to expand

if — runs a block of code when a condition is true.

if.cpp
int number;

if (number > 0) {
    std::cout << "The number is positive.";
}

else if — adds additional conditions after an if.

else-if.cpp
int number;

if (number > 0) {
    std::cout << "Positive";
} else if (number < 0) {
    std::cout << "Negative";
}

else — runs when every previous condition is false.

else.cpp
int number;

if (number > 0) {
    std::cout << "Positive";
} else if (number < 0) {
    std::cout << "Negative";
} else {
    std::cout << "Zero";
}

switch — selects one of many blocks based on a value.

switch.cpp
int day;

switch (day) {
    case 1:
        std::cout << "Monday";
        break;
    case 2:
        std::cout << "Tuesday";
        break;
    case 3:
        std::cout << "Wednesday";
        break;
    default:
        std::cout << "Other day";
}
Note

break stops execution from "falling through" into the next case.

5. Loops

Loops let you run a block of code repeatedly until a condition is met.

Click to expand

while — runs while a condition stays true.

while.cpp
int i = 1;
while (i <= 5) {
    std::cout << i << " ";
    i++;
}
// Output: 1 2 3 4 5

do-while — runs at least once, then repeats while a condition is true.

do-while.cpp
int i = 1;
do {
    std::cout << i << " ";
    i++;
} while (i <= 5);
// Output: 1 2 3 4 5

for — used when the number of iterations is known in advance.

for.cpp
for (int i = 1; i <= 5; i++) {
    std::cout << i << " ";
}
// Output: 1 2 3 4 5

range-based for (for-each) — simplifies traversing arrays or other containers.

range-for.cpp
int arr[] = {1, 2, 3, 4, 5};
for (auto element : arr) {
    std::cout << element << " ";
}
// Output: 1 2 3 4 5

6. Functions

Functions are blocks of code that perform a specific task — they can accept parameters and return a value.

Click to expand
functions.cpp
int add(int a, int b) {
    return a + b;
}

float multiply(float x, float y) {
    return x * y;
}

int main() {
    int sum = add(3, 5);                 // sum = 8
    float product = multiply(2.5, 4.0);  // product = 10.0

    std::cout << "Sum: " << sum << std::endl;
    std::cout << "Product: " << product << std::endl;

    return 0;
}

7. Function templates

A function template lets you write a single function that works across different data types.

Click to expand

Single-type template

template.cpp
template <typename T>
T max(T x, T y) {
    return (x > y) ? x : y;
}

int main() {
    max(2, 1);          // int
    max(2.987, 1.234);  // double
    max('4', '7');      // char
    max(true, false);   // bool
}

Template with two different types

template-two-types.cpp
template <typename T, typename U>
auto max(T x, U y) {
    return (x > y) ? x : y;
}

int main() {
    max(true, 2);  // bool and int
}
