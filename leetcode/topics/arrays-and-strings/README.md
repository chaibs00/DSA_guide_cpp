Contiguous data and indices. Patterns are listed in the order worth learning them — each one builds on the previous.

## 🧩 Patterns

| Step | Pattern | Use it when… | Problems |
|:-:|:--|:--|:-:|
| 1 | [**Traversal & simulation**](./basics.md) | Just walk the array / string once and track something. | `1` |
| 2 | [**In-place modification**](./in-place.md) | Rearrange or overwrite without extra memory. | `2` |
| 3 | [**Sorting first**](./sorting.md) | Order makes the problem easier (duplicates, anagrams, intervals). | `2` |
| 4 | [**Prefix sum**](./prefix-sum.md) | Many range-sum queries on a fixed array. | `1` |
| 5 | [**Hashing**](./hashing.md) | Fast lookup or counting of things already seen. | `3` |
| 6 | [**Two pointers**](./two-pointers.md) | Sorted input, or comparing from both ends. | `2` |
| 7 | [**Sliding window**](./sliding-window.md) | Best / longest / shortest contiguous subarray. | `1` |

> 📘 Theory for this topic lives in the DSA guide.
