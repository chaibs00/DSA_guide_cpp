## ➕ Adding a problem

1. Copy `templates/` to `problems/<id>-<slug>/` and fill in the README + `solution.cpp`
2. Add one line to [`data/problems.json`](./data/problems.json) with its tags
3. Run `python scripts/generate.py` — every topic, pattern and index page updates itself
