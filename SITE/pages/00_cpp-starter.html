C++ Introduction

C++ is a compiled, high-performance programming language widely used for system software, game engines, embedded systems, and competitive programming.

Requirements (C++ compiler)

C++ is a compiled language, so you'll need a compiler to run your code. A compiler translates what you write into machine instructions (binary) that the computer can execute directly.

Option 1 — local compiler

  • Windows: Installing MinGW to build C++ code on Windows
  • macOS: Set up C++ development with Visual Studio Code on Mac

Option 2 — online compiler

  • Programiz online C++ compiler — nothing to install, good for quick tests.
