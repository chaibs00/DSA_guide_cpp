1. Strings and character handling

C++ provides the std::string class to work with text. Strings are mutable — you can modify them after creation.

Click to expand

Declaring strings

Double quotes create a std::string; single quotes create a single char.

declaring.cpp
#include <string>

std::string str1 = "This is a string";  // double quotes -> std::string

char letter = 'A';   // single quotes -> char
char digit = '7';

Converting numbers and strings

Number → string

to-string.cpp
double num = 23.43;
std::string str = std::to_string(num);
std::cout << str;

Looping through a string

loop-string.cpp
std::string S = "Hello";

// Index-based loop
for (int i = 0; i < S.size(); i++)
    std::cout << S[i];

// Range-based loop
for (char ch : S)
    std::cout << ch;

2. Namespaces

Namespaces help prevent name conflicts in large projects by grouping identifiers under a named scope.

Click to expand

Custom namespaces

namespaces.cpp
#include <iostream>

namespace First {
    int x = 1;
}

namespace Second {
    int x = 2;
}

int main() {
    int x = 0;
    std::cout << x << std::endl;          // 0
    std::cout << First::x << std::endl;   // 1
    std::cout << Second::x << std::endl;  // 2

    return 0;
}

Using the standard namespace

The std namespace contains standard library components like cout, cin, endl, vector, string, and more.

using-std.cpp
#include <iostream>

using namespace std;

int main() {
    cout << "Hello world!";
}
Note

With using namespace std; in scope, you can write cout, cin, and endl without the std:: prefix.

3. Typedef and type alias

C++ lets you create aliases for existing data types.

Click to expand

An alias is simply an alternative name for a data type — useful for long or complex type names.

alias.cpp
#include <vector>

// `table_t` is an alias for `std::vector<int>`
typedef std::vector<int> table_t;
using table_t = std::vector<int>;  // modern syntax

int main() {
    table_t mytable;  // equivalent to std::vector<int> mytable;
}
Note

The using syntax is generally preferred over typedef for readability, especially with more complex types.

4. Classes

A class is a blueprint for creating objects — it can contain attributes (data members) and methods (functions).

Click to expand

Creating a class

class.cpp
#include <iostream>
#include <string>

class Human {
public:
    std::string name;
    std::string occupation;
    int age;

    void nameFunc() {
        std::cout << "Name: " << name << std::endl;
    }
};

int main() {
    Human human1;
    human1.name = "Alex";
    human1.occupation = "Nothing";
    human1.age = 89;

    human1.nameFunc();  // Output: Name: Alex
}
  • class Human defines a class named Human
  • name, occupation, and age are attributes (data members)
  • nameFunc() is a method that prints the name
  • human1 is an object of the Human class
  • Public members can be accessed and modified directly from the object

5. Structs

A struct groups related variables under one name. Unlike arrays, a struct can store variables of different types.

Click to expand

Creating a struct

struct.cpp
#include <iostream>
#include <string>

struct Point {
    int x;
    int y;
};

int main() {
    Point p1;
    p1.x = 10;
    p1.y = 20;

    std::cout << "Point: (" << p1.x << ", " << p1.y << ")";
}
Note

Structs are usually passed by value — passing one to a function creates a copy, so changes inside the function don't affect the original unless you pass by reference or pointer.
